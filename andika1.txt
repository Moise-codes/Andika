============================================================
2. PRODUCT DESCRIPTION
============================================================

ANDIKA is a modern typing-learning and typing-performance platform.

It combines:

- structured typing education
- typing practice
- typing tests
- performance analytics
- personalized recommendations
- achievements
- streaks
- leaderboards
- real-time typing competitions
- programming typing
- user profiles
- progress tracking

The objective is to create a serious product that helps users move
from learning basic keyboard skills to developing high-speed,
high-accuracy typing ability.

ANDIKA should serve:

- beginners
- students
- professionals
- developers
- competitive typists
- people improving typing accuracy
- people improving typing speed

24. SUPABASE SECURITY
============================================================

Use Row Level Security for exposed user data.

Users must only access data they are authorized to access.

Users must never be able to:

- modify official scores
- modify leaderboard records
- award themselves achievements
- modify another user's private data
- change their own role

Browser:

Use publishable Supabase credentials only.

Server:

Keep elevated/secret credentials server-side.

============================================================
40. ACCEPTANCE CRITERIA
============================================================

Every major feature must have explicit acceptance criteria.

Example:

Typing test:

Given a user starts a 60-second test,
when the timer reaches 60 seconds,
then typing stops,
then the client calculates a provisional result,
then the server validates the result,
then the validated result is persisted,
then the user sees the result analysis.

Do this for every major system.
