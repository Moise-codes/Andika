# ANDIKA - Feature Map

**Version**: 1.0  
**Date**: 2026-09-18  
**Status**: Draft

---

## 1. MVP Features (Phase 1 Launch)

### Authentication (P0)
- Email/password signup & login
- Google OAuth
- Email verification
- Password reset
- Session management

### Core Typing (P0)
- Typing engine (real-time tracking)
- Time-based tests (15s, 30s, 60s, 120s)
- Word-based tests (10, 25, 50, 100)
- Basic content modes (plain text)
- Results display (WPM, accuracy)
- "How You Typed" basic analysis

### Learning (P0)
- Course structure
- Lesson system
- Keyboard visualization
- Progress tracking
- Lesson completion

### Dashboard (P0)
- Overview metrics
- Quick actions
- Recent activity
- Streak display

### Themes (P1)
- Forest (default)
- Ivory
- Midnight

### Keyboard Layouts (P1)
- QWERTY
- AZERTY
- QWERTZ

### Analytics (P1)
- WPM progression
- Accuracy progression
- Basic charts
