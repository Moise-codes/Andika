## 2. Primary Personas

### 2.1 Beginner Student - "Alex"

**Demographics**
- Age: 18-22
- Occupation: University student
- Location: Urban area
- Tech literacy: Moderate

**Goals**
- Learn proper typing technique
- Improve typing speed for coursework
- Reduce errors in assignments
- Build confidence with keyboard

**Frustrations**
- Slow typing affects assignment completion time
- Frequent errors require constant corrections
- Peers type faster
- Unsure of proper finger placement

**Behaviors**
- Types with 2-4 fingers (hunt and peck)
- Looks at keyboard while typing
- Average WPM: 20-30
- Accuracy: 70-80%
- Practices sporadically when motivated

**Needs**
- Structured learning path
- Visual keyboard guidance
- Positive reinforcement
- Progress tracking
- Mobile-friendly for studying on-the-go

**ANDIKA Features Used**
- Learning courses
- Keyboard visualization
- Beginner lessons
- Progress dashboard
- Mobile analytics view

### 2.2 Professional - "Sarah"

**Demographics**

- Occupation: Marketing manager
- Location: Suburban area
- Tech literacy: High

**Goals**

**ANDIKA Features Used**

## 5. Persona Prioritization

### MVP Focus (Phase 1)
1. **Beginner Student** - Core learning experience
2. **Professional** - Core practice and analytics
3. **Developer** - Programming typing

### Post-MVP Focus
4. **Competitive Typist** - Competitions and leaderboards
5. **Accuracy-Focused User** - Advanced accuracy features
6. **Student** - Enhanced gamification

### Future Focus
7. **Accessibility User** - Enhanced accessibility
8. **Teacher** - Schools feature
9. **Team Lead** - Teams feature

## 6. Anti-Personas

### 6.1 Non-Typist
- Rarely uses keyboard
- Prefers voice input or mobile
- Not interested in improving typing skills
- **Not a target user**

### 6.2 Enterprise Admin
- Needs enterprise SSO
- Requires advanced compliance features
- Needs extensive admin controls
- **Future target (Enterprise tier)**

### 6.3 Casual Mobile User
- Only uses phone/tablet
- No physical keyboard
- Interested in casual games only
- **Not a primary target (typing requires physical keyboard)**

## 7. Persona Validation

### 7.1 Research Methods
- User interviews with target demographics
- Survey of existing typing platform users
- Competitive analysis of user bases
- Analytics from beta testing

### 7.2 Validation Criteria
- Persona represents significant user segment
- Persona has distinct needs from other personas
- Persona's goals align with ANDIKA value proposition
- Persona is technically feasible to support
