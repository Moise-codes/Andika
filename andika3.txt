8. VALIDATION
============================================================

Every external request must be validated.

Validate:

body
params
query
headers where necessary
WebSocket payloads

Reject:

unknown/malicious input
oversized payloads
invalid IDs
invalid enum values
invalid state transitions

Do not trust client-generated values.

============================================================
9. TYPING SESSION SYSTEM
============================================================

A typing session must have a controlled lifecycle.

Example:

CREATED
→ STARTED
→ ACTIVE
→ COMPLETED
→ VALIDATED

Possible failure states:

EXPIRED
CANCELLED
INVALID
FLAGGED

The server should maintain authoritative session state.
